Подзадача: Ввод расстояния доставки

Подзадача: Ввод времени заказа

Подзадача: Расчёт базовой стоимости доставки
Описание: Расчёт стоимости по тарифу в зависимости от расстояния

Описание: Определение, попадает ли заказ под бесплатную доставку

Подзадача: Проверка на час пик
Описание: Определение, попадает ли время в часы пик

Подзадача: Расчёт итоговой стоимости доставки
Описание: Применение надбавки за час пик

Подзадача: Вывод результата
Описание: Вывод стоимости доставки и итого к оплате

Функция 1: ReadOrderCost
Тип возврата: double
Аргументы: нет
Назначение: запрашивает у пользователя стоимость заказа, проверяет корректность ввода (число, не меньше нуля), при ошибке повторяет запрос.
Возвращает: стоимость заказа в рублях.

Функция 2: ReadDistance
Тип возврата: double
Аргументы: нет
Назначение: запрашивает расстояние доставки, проверяет корректность (число, больше нуля), при ошибке повторяет запрос.
Возвращает: расстояние в километрах.

Функция 3: ReadOrderHour
Тип возврата: int
Аргументы: нет
Назначение: запрашивает час заказа, проверяет корректность (число, диапазон 0–23), при ошибке повторяет запрос.
Возвращает: час заказа.

Функция 4: IsFreeDelivery
Тип возврата: bool
Аргументы:
double orderCost — стоимость заказа (руб.)
Назначение: проверяет, превышает ли стоимость заказа 2000 руб.
Возвращает: true, если доставка бесплатная, иначе false.

Функция 5: IsPeakHour
Тип возврата: bool
Аргументы:
int hour — час заказа
Назначение: проверяет, попадает ли час в промежутки 12:00–14:00 или 18:00–20:00.
Возвращает: true, если час пик, иначе false.

Функция 6: CalculateBaseDeliveryCost
Тип возврата: double
Аргументы:
double distance — расстояние доставки (км)
Назначние: рассчитывает базовую стоимость доставки: 150 руб. при расстоянии до 3 км, далее +50 руб. за каждый дополнительный километр.
Возвращает: базовую стоимость доставки.

Функция 7: CalculateDeliveryCost
Тип возврата: double
Аргументы:
double orderCost — стоимость заказа
double distance — расстояние
int hour — час заказа
Назначение: вычисляет итоговую стоимость доставки с учётом бесплатной доставки и надбавки за час пик (+30%).
Возвращает: стоимость доставки.

Функция 8: PrintResult
Тип возврата: void
Аргументы:
double deliveryCost — стоимость доставки
double orderCost — стоимость заказа
Назначение: выводит стоимость доставки и итого к оплате.

Функция 9: Main
Тип возврата: void
Аргументы: string[] args
Назначение: организует вызовы остальных функций.

Алгоритм решения подзадач
Вызвать ReadOrderCost() → получить стоимость заказа.
Вызвать ReadDistance() → получить расстояние.
Вызвать ReadOrderHour() → получить час.
Вызвать CalculateDeliveryCost(orderCost, distance, hour):
Если IsFreeDelivery(orderCost) → вернуть 0.
Иначе вычислить baseCost = CalculateBaseDeliveryCost(distance).
Если IsPeakHour(hour) → baseCost *= 1.3.
Вернуть baseCost.
Вызвать PrintResult(deliveryCost, orderCost).

Реализуется написанным кодом:
static void Main(string[] args)
{
    double orderCost = Class1.ReadDouble("Введите стоимость заказа (руб.): ", 0);
    double distance = Class1.ReadDouble("Введите расстояние доставки (км): ", 0);
    int hour = Class1.ReadInt("Введите время заказа (час): ", 0, 23);

    double delivery = Class1.CalcDelivery(orderCost, distance, hour);
    double total = orderCost + delivery;

    Console.WriteLine($"Стоимость доставки: {delivery} руб.");
    Console.WriteLine($"Итого к оплате: {total} руб.");
}


internal class Class1
{
    public static double CalcDelivery(double orderCost, double distance, int hour)
    {
        if (orderCost >= 2000) return 0;

        double basePrice = 150;
        if (distance > 3)
            basePrice += (distance - 3) * 50;

        if (IsPeakHour(hour))
            basePrice *= 1.3;

        return basePrice;
    }
    public static bool IsPeakHour(int hour)
    {
        return (hour >= 12 && hour <= 14) || (hour >= 18 && hour <= 20);
    }
    public static int ReadInt(string prompt, int min, int max)
    {
        while (true)
        {
            Console.Write(prompt);
            if (int.TryParse(Console.ReadLine(), out int v) && v >= min && v <= max)
                return v;
            Console.WriteLine("Ошибка! Повторите ввод.");
        }
    }
    public static double ReadDouble(string prompt, double min)
    {
        while (true)
        {
            Console.Write(prompt);
            if (double.TryParse(Console.ReadLine(), out double v) && v >= min)
                return v;
            Console.WriteLine("Ошибка! Повторите ввод.");
        }
    }

}
